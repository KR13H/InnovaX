## Brand & Style

This design system drives a elite sports-tech paradigm: human kinetics augmented by an AI digital twin. The aesthetic fuses **high-performance athletic minimalism** with **cybernetic telemetry glassmorphism**. It rejects toy-like gamification in favor of an authoritative, surgical, and cinematic atmosphere akin to an F1 telemetry console crossed with Olympic-tier training monitors.

The core visual narrative relies on the interplay of two entities:
- **The Physical Athlete**: Expressed through relentless, ultra-vibrant electric lime CTA vectors, representing kinetic energy, active output, and immediacy.
- **The Shadow Twin**: Expressed through luminous, ethereal cyan overlays and data streams, representing theoretical limits, benchmark targets, and biomechanical ghost trails.

Surfaces feel low-gravity yet dense, using dark charcoal tiers paired with frosted glass blurs, hair-thin tech borders, and focused ambient glows that activate only on key performance metrics.

## Colors

The palette is engineered exclusively for a deep-slate, low-reflection dark environment. Contrast ratios strictly satisfy WCAG AAA standards for critical telemetry and interactive elements.

### Base Canvases & Structural Tiers
- **Canvas Base (`#0D1117`)**: Deepest void backdrop; isolates bright kinetic overlays.
- **Surface Layer 1 (`#161B22`)**: Primary card background, data grid modules, navigation docks.
- **Surface Layer 2 (`#21262D`)**: Interactive card hovers, modal overlays, nested parameter trays.
- **Surface Stroke (`#30363D`)**: Precise 1px hairline boundary separating surfaces and graphs.

### Active Kinetic Accents
- **Primary Kinetic Lime (`#22C55E` / Accent: `#39FF14`)**: Represents live real-world athlete execution, primary action buttons, positive deltas (+%), and high-readiness indexes.
- **Secondary Shadow Cyan (`#00F0FF` / Accent: `#06B6D4`)**: Represents AI twin projections, ghost trajectory traces, telemetry radar meshes, and comparative milestones.

### Sport Modality Disciplines
- **Running / Biomechanics**: Electric Cyan (`#00F0FF`)
- **Tennis / Kinetic Racket**: Electric Lime & Court Gold (`#A3E635` / `#EAB308`)
- **Basketball / Vertical Power**: Warm Amber-Orange (`#F97316` / `#F59E0B`)
- **Cricket / Precision Pitch**: High-Grade Emerald (`#10B981`)

### Typography & Content Greys
- **High-Emphasis Content (`#F0F6FC`)**: Metric digits, hero headlines, active switch states.
- **Medium-Emphasis Content (`#C9D1D9`)**: Body telemetry, labels, inactive tooltips.
- **Muted Metadata (`#8B949E`)**: Units (km/h, ms, rpm), timestamps, axis borders.

## Typography

The type system balances technical precision and athletic aggression.

- **Headlines & Metric Data (`Space Grotesk`)**: Imparts an instrumented, technical posture. Used across main dashboards, analytical split counters, metric values, and primary component titles. Metric figures utilize tabular lining numbers to avoid jitter during real-time streaming updates.
- **Continuous Reading & Body Telemetry (`Inter`)**: Neutral, highly legible grotesque with optical corrections for low-light legibility. Used for clinical AI coaching feedback, log items, and descriptive biomechanical commentary.
- **Telemetry Tags (`label-caps`)**: All technical sub-labels, axis units, and state metadata must be displayed uppercase with extended tracking (`letterSpacing: 0.08em`) to mimic aerospace cockpit readouts.

## Layout & Spacing

The layout model runs on a modular **12-column fluid responsive grid** anchored inside high-density viewport boundaries.

### Rhythm & Breakpoints
- **Mobile (< 768px)**: 4 columns, `margin-mobile` (16px), `gutter-mobile` (12px). UI stacks strictly into vertical telemetry streams with floating kinetic control pills at thumb level.
- **Tablet (768px - 1024px)**: 8 columns, 24px margins, 16px gutters. Analytical split view activated (Left: Live Feed / 3D Canvas, Right: Metrics Split).
- **Desktop (> 1024px)**: 12 columns, max bounded container width of 1600px with `margin` (40px) and `gutter` (24px). Accommodates concurrent visual twin meshes, parametric radar clusters, and multi-session historical scatter graphs.

Spacings are tightly coupled to powers of 4 and 8. Data chips and indicators use dense paddings (`space-xs`, `space-sm`) to maximize analytical screen real estate without clutter.

## Elevation & Depth

Visual hierarchy is maintained through **layered tonal luminescence and frosted glassmorphism**, never using muddy drop shadows.

1. **Surface 0 (Ground/Pitch - `#0D1117`)**: Base flat canvas where 3D twin wireframes and skeletal node visualizations operate.
2. **Surface 1 (HUD Telemetry Layer - `#161B22` at 85% opacity, backdrop blur 16px)**:
   - Floating panels and data modules.
   - Border: 1px continuous solid `#30363D`.
   - Shadow: 0 8px 32px -4px rgba(0, 0, 0, 0.65).
3. **Surface 2 (Ghost Comparison Overlays - `rgba(22, 27, 34, 0.75)`, backdrop blur 24px)**:
   - Real-time comparison sidebars and delta inspector drawers.
   - Border: 1px dynamic gradient stroke (`#30363D` transitioning to `#00F0FF` at 30% alpha).
4. **Active Elevation (Aura Glows)**:
   - When a parameter beats the Shadow Twin, the component emits an ambient, low-spread lime ray (`box-shadow: 0 0 24px -2px rgba(34, 197, 94, 0.25)`).
   - When viewing the digital twin in ghost inspect mode, cards project a focused cyan glow (`box-shadow: 0 0 24px -2px rgba(0, 240, 255, 0.2)`).

## Shapes

The design system employs a **technical-soft geometry (`roundedness: 1`)**. 

- **Cards & Data Modules**: Base corner radius is `0.375rem` (6px) to `0.5rem` (8px). This creates structural, instrument-grade cards that lock cleanly into dense modular grids.
- **Controls & Data Badges**: Fully pill-shaped (`rounded-full` / 9999px) for status indicators, metric delta badges, and primary kinetic triggers. This stark juxtaposition between architectural rectangular modules and fluid pill controls differentiates visual telemetry from physical actions.

## Components

### Buttons
- **Primary Kinetic Trigger**: Solid vibrant lime (`#22C55E`), text `#0D1117` in Space Grotesk Bold. On hover, shifts to intense neon `#39FF14` with a dynamic 16px soft outer radiance.
- **Shadow Twin Comparative Action**: Ethereal cyan stroke (`#00F0FF` at 1px), semi-transparent cyan background (`rgba(0, 240, 255, 0.08)`), text `#00F0FF`.
- **Ghost/Tertiary**: Surface fill `#21262D`, text `#C9D1D9`, border `#30363D`.

### Badges & Pill Chips
- Pill geometry with uppercase `label-caps` typography.
- Status badges feature a pulsating 6px core dot:
  - Active Session: Glowing Lime.
  - Twin Syncing / AI Processing: Luminous Cyan.
  - Target Deficit: Warm Amber (`#F59E0B`).

### Kinetic & Shadow Attribute Bars
- Split-rail horizontal indicators with a 4px height and 2px border radius.
- Track runs on `#21262D`. 
- Dual-indicator setup:
  - Bottom Bar (Cyan `#00F0FF` at 60% opacity): The Shadow Twin benchmark.
  - Top Bar (Lime `#22C55E` with glowing tip): The Athlete's current session benchmark.
  - Lead indicator displays delta markers (`+2.4 km/h` or `-12 ms`).

### Telemetry Cards
- Built on `#161B22` with 1px border `#30363D` and subtle 12px backdrop filtering.
- Header contains uppercase category track with sport-specific accent dots.
- Primary values utilize `metric-large` font metrics paired with high-contrast units (`#8B949E`).

### High-Contrast Inputs & Selectors
- Background: `#0D1117`, resting border: 1px `#30363D`.
- Focus state: Instant transition to 1px `#00F0FF` border with a subtle cyan glow (`0 0 0 1px #00F0FF`). Text color is pure `#F0F6FC`.

### Radar & Skeletal Visualizer Canvas
- Dark polygon grids rendered with `#21262D` gridlines.
- Dual-filled vector meshes:
  - User polygon: Solid stroke `#22C55E` (2px), fill `rgba(34, 197, 94, 0.15)`.
  - Twin polygon: Dashed stroke `#00F0FF` (1.5px), fill `rgba(0, 240, 255, 0.1)`.
